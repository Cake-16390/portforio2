ผลงานของฉัน

รวมผลงานที่ได้จัดทำระหว่างการเรียน และผลงานที่เกี่ยวข้องกับคอมพิวเตอร์ การออกแบบ และเทคโนโลยี

💻 เว็บไซต์ Portfolio

เว็บไซต์ Portfolio ส่วนตัว สำหรับรวบรวมประวัติส่วนตัว ผลงาน และเกียรติบัตร

เทคโนโลยี: HTML, CSS

🌐 เว็บไซต์

ผลงานการออกแบบเว็บไซต์ สำหรับฝึกทักษะด้านการสร้างเว็บไซต์ และการจัดวางองค์ประกอบ

เทคโนโลยี: HTML, CSS, JavaScript

🎨 งานออกแบบ

ผลงานออกแบบโปสเตอร์ สื่อประชาสัมพันธ์ และงานกราฟิกสำหรับกิจกรรมต่าง ๆ

เครื่องมือ: Canva

🐍 โปรแกรม Python

โปรแกรมที่สร้างขึ้นเพื่อฝึก การเขียนโปรแกรม และการคิดแก้ปัญหาอย่างเป็นระบบ

ภาษา: Python

📊 งานนำเสนอ

การจัดทำสื่อนำเสนอสำหรับรายวิชา และกิจกรรมต่าง ๆ โดยเน้นการออกแบบให้สวยงาม และเข้าใจง่าย

เครื่องมือ: PowerPoint, Canva

🚀 โปรเจกต์ในอนาคต

เป้าหมายในการพัฒนาเว็บไซต์ และโปรแกรมที่มีความสามารถมากขึ้น เพื่อเพิ่มประสบการณ์ด้านเทคโนโลยี

เป้าหมาย: Web Development
